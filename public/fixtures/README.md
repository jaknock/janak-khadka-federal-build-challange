# Synthetic fixture scenarios

Use fictional images only when demonstrating the inbox prototype. Cover: a complete
matching label, a changed ABV, a modified warning, missing warning, mixed-case warning
heading, glare, and skewed photography. Do not add real applications or personally
identifiable information.

Old Tom Distillery variants. They exercise the conservative **Needs review** path when
the model reports unreadable or low-confidence visual evidence.
